# BorrowFour

Four-bar borrowed-harmony desk for bedroom producers and AI-music finishers.

The loop never leaves the key, so it cannot end. BorrowFour spends four bars on one outside color (minor four, flat six, five of five, parallel minor, Neapolitan, flat seven), then the return lands on the tonic instead of the turnaround.

Live chairs only: FluidR3 piano, nylon, upright, kit, trumpet, violin (samples hosted with PreEight).

Distinct from BreathFour (air between chorus and verse), PreEight (pre-chorus), ModEight (whole last-chorus key change), LiftTwo, TagFour, ThinFour, HookGrid, MixForge, AuraMix, VocalForge.

## Form

1–4 home loop · 5–8 borrow · 9–12 return on the tonic

## Play

- A · Home loop
- B · Full twelve
- 8 · Borrow + return

Download the MIDI and drop it in the DAW. Do not paste the home loop into the last four bars.
